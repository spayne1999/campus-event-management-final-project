README3 - How to Run the Integration Tests
=============================================

1. Open `3_integration_testing/integration-tests.html` in a browser.
2. Review the PASS/FAIL style status messages.
3. These tests simulate a realistic workflow:
   - system boot
   - event creation
   - attendee registration
   - storage persistence
   - metrics refresh

This complements the unit tests by checking interaction between multiple modules.
