README1 - How to Run the Code
================================

Option 1: Run locally
1. Open the folder `1_code`.
2. Double-click `index.html`, or right-click and open it in Chrome/Edge/Firefox.
3. Use the forms to create events and register attendees.
4. The application stores data in the browser using localStorage.

Option 2: Run through GitHub Pages
1. Upload the full project folder to GitHub.
2. Enable GitHub Pages from the root branch.
3. The repository root `index.html` redirects to `1_code/index.html`.

Code overview
-------------
- index.html: main user interface
- style.css: responsive styling
- logic.js: reusable business logic and validation
- app.js: DOM rendering and user interactions
- data/schema.sql: relational database schema draft
- data/sample-events.json: sample event data
