Campus Event Management Database System

A browser-based event management dashboard that helps student organizations and staff create events, track registrations, and monitor campus engagement with minimal manual work.

System Highlights

  • Fast event creation and validation
  • Automatic registration totals and fill-rate tracking
  • Search and filter support for quick event discovery
  • Local storage persistence for lightweight deployment
