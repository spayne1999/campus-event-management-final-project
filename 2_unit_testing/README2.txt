README2 - How to Run the Unit Tests
======================================

1. Open `2_unit_testing/unit-tests.html` in a browser.
2. Review the PASS/FAIL output list.
3. These tests validate the reusable functions in `1_code/logic.js`.

What is covered
---------------
- default seeded state
- event input validation
- successful event creation
- successful attendee registration
- duplicate registration blocking
- stat recalculation
- event filtering
