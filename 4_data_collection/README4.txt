README4 - How to Run the Data Collection Utility
================================================

1. Open the main demo in `1_code/index.html`.
2. Create or register sample data.
3. Open `4_data_collection/export_data.html`.
4. Click `Load Current Demo Data`.
5. The current event and attendee dataset will appear as JSON for backup or review.

Why this folder exists
----------------------
This file demonstrates how the project can export collected event and registration data
for reporting, backup, or later database migration.
