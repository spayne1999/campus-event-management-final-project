# Campus Event Management Database System

This repository contains the final project package for a campus event management system.

## Live Demo
If this repository is published with GitHub Pages from the root folder, the demo starts from `index.html` and redirects to `1_code/index.html`.

## Folder Structure
- `1_code` - source code for the working demo
- `2_unit_testing` - unit testing files and instructions
- `3_integration_testing` - integration testing files and instructions
- `4_data_collection` - data export collection utility
- `5_documentation` - system requirements PDF, brochure PDF, and presentation slides PDF

## Quick Start
Open `1_code/index.html` in a browser, or publish the repository with GitHub Pages.
